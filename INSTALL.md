# Amiwi Installation (Easy)

## Windows (quick install)
1. Open PowerShell.
2. Run:
```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
.\scripts\install-windows.ps1
```

## macOS (quick install)
1. Open Terminal.
2. Run:
```bash
chmod +x ./scripts/install-macos.sh
./scripts/install-macos.sh
```

## Manual install
- Go to Releases: `https://github.com/jdsalasca/amiwi/releases`
- Download the latest installer for your OS.
- Run installer and follow steps.

## Floating companion quick controls
- `Minimal`: collapses to lightweight compact mode.
- `Minimize`: sends Amiwi to the taskbar/dock quickly.
- `Settings`: full controls for language, avatar, phrase behavior, and music detection.
