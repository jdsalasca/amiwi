# Product Vision: Living Pet

## North star
Build a desktop pet that feels alive and relational, not decorative.

## Value pillars
1. Presence
- The pet should always feel "awake": blinking, gaze, micro-motions, contextual idle loops.

2. Reciprocity
- User actions produce immediate emotional feedback (petting, dragging, shaking, focus sessions).

3. Personality
- Reactions vary by context (focus/work/break/music) and by relationship strength (bond).

4. Minimal friction
- Keep interactions lightweight and playful without bloating controls.

## Interaction roadmap
1. Foundation (done)
- Anime beta avatar with blinking/eyes/mouth.
- Dance profiles tied to music energy.
- Cute liquid-glass bubble bursts.
- Drag and shake reactive behavior.

2. Life system (in progress)
- Persistent bond state.
- Bond-aware phrases and visual cues.
- Positive/negative drift over time.

3. Deeper relationship (next)
- Memory snippets ("you focused 3 times today").
- Personality modes (shy, energetic, calm).
- Contextual emotes per user habit.

4. Premium interaction (future)
- Rich animation states (walk loops, sit/stand, surprise).
- Track-aware reactions when metadata is available.
- Lightweight progression system with non-intrusive rewards.

## Product constraints
- Fast startup.
- Zero UI clutter in minimal mode.
- No fragile platform-specific dependencies for core loop.
- All new interactions must degrade gracefully.
